# GitHub Labels

Create these labels after launch.

| Label | Purpose |
| --- | --- |
| `good first issue` | Beginner-friendly tasks |
| `help wanted` | Contributions actively requested |
| `benchmark` | Benchmark records, tasks, and methods |
| `cli` | Local command-line tooling |
| `schema` | JSON schemas and validation |
| `reports` | Generated and human-written reports |
| `prompt-set` | Benchmark prompts |
| `model-adapter` | Model-specific setup and execution |
| `research` | Evaluation methods and analysis |
| `governance` | Maintainer and decision process |
| `data` | Dataset and provenance work |
| `safety` | Abuse prevention, privacy, and legal risk |
| `docs` | Documentation improvements |
| `bug` | Reproducible defects |
