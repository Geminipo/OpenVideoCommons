# Choose content, benchmark, and dataset licenses

Labels: `governance`, `data`, `safety`, `help wanted`

## Goal

Recommend licensing choices for project content beyond code.

Code currently uses MIT. We still need clear choices for:

- Documentation.
- Prompt sets.
- Benchmark result records.
- Public reports.
- Future curated datasets.

## Questions To Answer

- Should reports and docs use CC BY 4.0?
- Should prompt sets use CC0, CC BY, or another license?
- Should benchmark records allow commercial reuse?
- What license constraints should future datasets require?
- How should contributors certify provenance and rights?

## Deliverable

Create an RFC under `docs/rfcs/` recommending licenses and explaining trade-offs.

## Acceptance Criteria

- The recommendation distinguishes code, docs, reports, records, prompts, and datasets.
- The recommendation considers open research and commercial reuse.
- The recommendation includes contributor provenance requirements.
