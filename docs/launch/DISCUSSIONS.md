# GitHub Discussions Starter Posts

Enable GitHub Discussions after launch, then create these starter threads.

## Introduce Yourself And Your Hardware

Category: General

Title: Introduce yourself and your hardware

Body:

Tell the community what you can contribute.

- GitHub handle:
- Country/time zone, optional:
- Hardware:
- Operating system:
- Video AI models you have tried:
- Interested in: benchmarks, prompts, model adapters, data governance, evaluation, safety, docs

## Which Open Video Model Should We Benchmark First?

Category: Ideas

Title: Which open video model should OpenVideoCommons benchmark first?

Body:

We need the first official model adapter target.

Please suggest models with:

- Repository link.
- License.
- Minimum hardware requirements.
- Why it matters.
- Known setup issues.

## Prompt Set Review: motion-basic-v1

Category: Ideas

Title: Review the first prompt set: motion-basic-v1

Body:

The first prompt set lives at `prompts/motion-basic-v1.json`.

What should we add, remove, or rewrite to better test:

- Motion consistency.
- Camera movement.
- Object persistence.
- Human and animal motion.
- Reflections, water, lighting, and temporal artifacts.
