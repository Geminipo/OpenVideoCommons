# OpenVideoCommons Manifesto

Video AI will shape how people create, learn, simulate, document, and understand the world. If the foundations of this technology are built only inside closed labs, society gets powerful tools without shared visibility into their data, limits, failures, and trade-offs.

OpenVideoCommons exists to build the open coordination layer for video AI.

We believe open communities can contribute something closed labs cannot easily buy: broad participation, real-world diversity, transparent evaluation, public accountability, and shared ownership of the improvement process.

## Our Mission

Build a global open lab where anyone can help evaluate, improve, curate, and eventually train open video foundation models.

## Our Strategy

First we measure. Then we improve. Then we train.

We start with evaluation because credible measurement is the foundation of credible progress. Before asking the world to contribute compute for training, we need to prove that global contributors can produce reliable, reproducible, useful records.

## What Contributors Can Do

Contributors can:

- Run open video models on real consumer hardware.
- Submit standardized benchmark results.
- Review generated videos for quality, safety, and failure modes.
- Design prompt sets and evaluation criteria.
- Improve model adapters and inference scripts.
- Curate legal, traceable, high-quality video data workflows.
- Publish open reports that help the whole ecosystem.

## What We Refuse

We refuse to build a project on unverifiable claims, copyright-unclear data, speculative token incentives, or hype about training capabilities we have not earned.

This is not a shortcut around hard engineering. It is a path toward doing hard engineering openly.

## The Long View

If we can build a trusted global benchmark network, we can build trusted data workflows. If we can build trusted data workflows, we can build reproducible fine-tuning and distillation pipelines. If we can build those, then community-trained video foundation models become a serious goal rather than a slogan.

Open video AI needs a commons.

This is where we begin.
